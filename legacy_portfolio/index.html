// 04. OUR METHODOLOGY

The 36-Hour Winning Playbook

We don't rely on luck. Over 14 hackathons, we refined an unshakeable sprint formula.

01
HOURS 00 — 04

Ruthless Idea Validation

We pitch 10 ideas and brutally kill 9 within 45 minutes. We review judge rubrics, define the "Hero Moment" (the 10-second jaw-dropper demo), and freeze API contracts.

  • Review sponsor bounties & judge criteria
  • Wireframe the 3 core screens in Figma
  • Setup Git repo, linting, CI, and stub API endpoints
02
HOURS 04 — 20

The Deep Core Sprint

Parallel execution in isolated branches. Frontend works against typed mock JSON schemas while Backend & AI spin up model endpoints. Zero scope creep permitted.

  • Implement working core data pipeline
  • Component library assembled with Tailwind
  • Hour 16 Checkpoint: Merge frontend & backend draft
03
HOURS 20 — 28

Polish & Realistic Data

Judges hate empty states and "Lorem Ipsum". We seed real-world datasets, polish micro-interactions, add fallback error states, and ensure 60fps responsiveness.

  • Populate production-grade mock data & edge cases
  • Harden latency & graceful model fallbacks
  • Deploy live preview URLs on Vercel / Cloudflare
04
HOURS 28 — 36

The Hollywood Pitch

50% of winning is storytelling. Sophia writes the hook, Marcus records high-def b-roll backups, and Alex & Elena rehearse the live demo until failure is impossible.

  • Record backup offline video of full demo flow
  • Craft 3-minute pitch deck: Problem, Solution, Market, Tech
  • 3x live timed run-throughs with mock harsh questions
